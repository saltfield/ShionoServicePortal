# Documentテンプレート作成ガイド

テンプレート（HTML / Excel / XML）内に `{{置換コード}}` を埋め込むと、契約 activate（または再生成）時に実データへ差し替えられ、**PDF** として契約明細に保存されます。

## 記法

- 形式: `{{code}}`（半角、プレフィックスなし）
- ユーザー定義コード: `^[a-z][a-z0-9_]*$`
- 未知のコード: 空文字（生成継続）
- **予約語**はユーザー定義として登録・入力不可（システム占有）

## 予約語一覧（短いコード）

発行者は契約の管理BP（owning / managing BP）を指す。

### BP（発行者）

| コード | 内容 |
|--------|------|
| `bp_name` | BP名 |
| `bp_code` | BPN |
| `bp_addr` | 住所（郵便番号・住所・建物を連結） |
| `bp_tel` | 電話 |
| `bp_mail` | メール |

### カスタマー

| コード | 内容 |
|--------|------|
| `c_name` | カスタマー名 |
| `c_code` | CN |
| `c_addr` | 住所（連結） |
| `c_tel` | 電話 |
| `c_mail` | メール |

### 拠点

| コード | 内容 |
|--------|------|
| `s_name` | 拠点名 |
| `s_addr` | 設置住所（連結） |
| `s_tel` | 設置先電話 |
| `sb_name` | 請求送付先宛名 |
| `sb_addr` | 請求送付先住所（連結） |
| `sb_tel` | 請求送付先電話 |

### 契約・品目・価格・税

| コード | 内容 |
|--------|------|
| `ctr` | 契約番号 |
| `icode` | 品目コード |
| `iname` | 品目名 |
| `price` | ユーザー請求額（税別） |
| `price_in` | ユーザー請求額（税込） |
| `tax` | 消費税額（請求額側） |
| `rate` | 税率（%） |
| `part` | 仕切り（税別） |
| `part_in` | 仕切り（税込） |
| `part_tax` | 仕切りの消費税額 |

計算: `tax = price × rate/100`（整数円は実装時に四捨五入方針を TaxPrice に合わせる）。`price_in = price + tax`。

## ユーザー定義の置換コード

1. データ名称マスタで「表示名」＋「置換コード」を登録  
2. 契約データでマスタ選択時はそのコードを使用  
3. マスタ外入力では置換コード必須  
4. 上表の予約語と同名は登録不可  

例: 表示名「回線ID」、コード `line_id` → `{{line_id}}`

## HTML 例

```html
<h1>開通案内</h1>
<p>発行: {{bp_name}}（{{bp_tel}}）</p>
<p>お客様: {{c_name}}（{{c_code}}）</p>
<p>拠点: {{s_name}} / {{s_addr}}</p>
<p>品目: {{iname}}（{{icode}}）</p>
<p>月額: {{price}} 円（税別）／税込 {{price_in}} 円（税額 {{tax}} 円・税率 {{rate}}%）</p>
<p>回線ID: {{line_id}}</p>
```

## 再生成

同一テンプレート由来の PDF は **上書き**（版管理なし）。
