## B. ユーザーアカウント管理UI（確定スコープ）

### 現状

- 管理者: 特権のみ（PW強制変更 / 2FA緊急スキップ）
- アカウント CRUD UI なし

### 操作主体（確定）

| 操作者 | Phase 7 でできること |
|--------|----------------------|
| **管理者** | 管理者ユーザー / BPユーザー / **カスタマーユーザー** の CRUD、ロール付与、有効無効、特権操作 |
| **BP**（`iam.user.manage` 等） | **自配下**の BPユーザー・カスタマーユーザーの CRUD、ロール付与、有効無効 |
| **カスタマー** | ユーザー作成・一覧管理 UI **なし**（別フェーズ） |
| **本人（全種別）** | アカウントメニューからパスワード・2FAのみ（A） |

補足: 「カスタマーユーザー」のアカウント自体は、**管理者または管理BPが代理作成**する。カスタマーログイン後に自分でメンバーを増やす機能は別フェーズ。

### 画面・権限

- 権限: `iam.user.manage` を本格利用（BPロールへ必要なら付与を見直す）
- `/admin/users` … 本管理＋既存特権を統合
- `/bp/users` … 配下スコープのみ
- `/customer/*` … ユーザー管理ルートを追加しない
- 作成項目: login_id、氏名、メール、初期PW（仮PW＋強制変更可）、紐づき（管理者/BPN/CN）、ロール
- 削除: 論理削除＋確認コード
- 制約: 1ユーザー=1BP または 1カスタマー。兼務は別アカウント

| Step | 内容 |
|------|------|
| 7-B1 | `UserManagementService` TDD（admin/BPスコープ。customer actor からの作成は拒否） |
| 7-B2 | 管理者 UI |
| 7-B3 | BP UI |
| 7-B4 | 監査（user.create / update / disable 等） |

## D. 契約ファイル生成（置換コード ＋ PDF化）

### 背景

現状はテンプレートの **コピーのみ**。契約時に入力する名称:値は文書に載らず、差し込みキーもない。

### ゴール（今回の意向）

1. 契約時にユーザーが提供する情報に **置換コード** を設定できる  
2. 各テンプレート内の `{{置換コード}}` を実値で置換する  
3. 置換後に **PDF化** し、契約明細の成果物として保存・DLする  

```text
データ項目: 名称「回線ID」 / 置換コード「line_id」 / 値「ABC-001」
テンプレート: 回線: {{line_id}}
        │ 置換
        ▼
中間HTML等: 回線: ABC-001
        │ PDF化（Dompdf + Noto）
        ▼
成果物.pdf → 契約画面から DL
```

### 1. 置換コードの設定

#### 名称マスタ（管理者）

`data_field_names` に `replace_code` を追加。

| カラム | 説明 |
|--------|------|
| `name` | 画面表示名（例: 回線ID） |
| `replace_code` | **新規**。テンプレ用キー（例: `line_id`）。英数字＋`_`、一意 |
| `is_active` | 既存 |

#### 契約明細データ入力

| パターン | 置換コード |
|----------|------------|
| マスタから選択 | マスタの `replace_code` を使用（読取専用表示） |
| マスタ外の直接入力 | **置換コードも必須**（`contract_item_data.replace_code` を追加） |

テンプレートは表示名ではなく **置換コードのみ** を参照する。表示名変更でテンプレを直す必要がない。

#### システム既定コード（入力不要）

顧客・拠点・契約なども同じ `{{code}}` 記法で差し込む（正式一覧は 7-D0 で確定）。

例: `{{customer_name}}` `{{customer_code}}` `{{site_name}}` `{{site_address}}` `{{contract_code}}` `{{item_code}}` `{{item_name}}` `{{unit_price}}` 等。

### 2. 生成パイプライン（成果物は常に PDF）

```text
activate / 再生成
  → 明細×品目テンプレートごと
  → (1) テンプレ読込（HTML / Excel / XML）
  → (2) {{置換コード}} を実値で置換
  → (3) PDF に変換
  → (4) contract_item_documents に PDF 保存（上書き）
```

| タイミング | 誰が | 動作 |
|------------|------|------|
| 契約 activate | システム | 自動生成 |
| 再生成 | 管理者 / BP | 同一テンプレ成果物を **上書き** |
| DL | 管理者 / BP / カスタマー | PDF をダウンロード |

#### 形式ごとの PDF 化

| テンプレート | 置換 | PDF化 |
|--------------|------|--------|
| HTML | `{{code}}` 置換 | Dompdf + Noto（**主経路**） |
| Excel | セル文字列の置換 | 内容を簡易HTML化 → Dompdf |
| XML | テキスト置換 | HTMLに包む → Dompdf |

成果物 MIME は常に `application/pdf`。元形式は `item_document_id` から追跡。  
未知コードは空文字。テンプレ欠損は当該件スキップ＋監査。

### 3. 画面への影響

| 画面 | 変更 |
|------|------|
| データ名称マスタ | 置換コードの登録・編集 |
| 契約明細データ | マスタ外は置換コード必須。マスタ選択時はコード表示 |
| 品目 Documentテンプレート | システムコード／置換コードのヘルプ |
| 契約詳細ドキュメント | PDF一覧・DL・再生成（admin/BP） |

### Step

| Step | 内容 |
|------|------|
| 7-D0 | 置換コード命名規則・システムコード一覧を Document 化 |
| 7-D1 | マイグレーション（`replace_code` 追加） |
| 7-D2 | 名称マスタ・契約データ入力 UI |
| 7-D3 | `DocumentRenderService` TDD（置換 → PDF） |
| 7-D4 | activate / 再生成。コピー処理を置換 |
| 7-D5 | 契約画面・テンプレヘルプ |

**含めない:** 帳票デザイナ、条件分岐DSL、Word、メール自動送付、版管理。
