# 価格の種類と使い分け

品目・卸・カスタマー・契約・請求で出てくる金額の意味と、システム上の使われ方をまとめる。  
金額は原則 **税別（整数円）**。画面では税込を併記する。

## 早見表

| 画面上の名称 | カラム / 場所 | 役割 | 請求・計算への影響 |
|--------------|---------------|------|-------------------|
| **標準仕切り** | `items.partition_price` | BP 間卸の**既定値** | 卸価格未設定時のフォールバック |
| **推奨価格** | `items.recommended_price` | カタログ上の**目安・推奨売価** | **計算には使わない**（参照のみ） |
| **ユーザー標準** | `items.user_price` | カスタマー向け売価の**既定値** | カスタマー価格未設定時のフォールバック。契約 EU単価の初期値 |
| **卸価格（仕切り）** | `bp_wholesale_prices.amount` | 親BP→直接の子BP の卸 | 契約仕切りの初期値・キックバック下値 |
| **カスタマー価格** | `customer_prices.amount` | BP→特定カスタマーの売価 | 契約 EU単価の初期値（ユーザー標準より優先） |
| **請求額（EU単価）** | `contract_items.unit_price` | 契約上のカスタマー請求単価 | **カスタマー請求の金額** |
| **仕切り（契約）** | `contract_items.partition_price` | 契約上の管理BP側仕切り | キックバック計算の下値（請求額には使わない） |
| **価格レイヤ** | `contract_item_price_layers` | 承認時の親子区間仕切りスナップショット | 多段キックバックの計算根拠 |

---

## 1. 品目マスタ上の3価格

品目作成・編集画面（管理者／BP独自品目）で入力する。

### 標準仕切り（`partition_price`）

- **意味**: 親→子 BP に卸すときの標準的な仕切り金額。
- **使うとき**: `bp_wholesale_prices` に当該親子・品目の行が無い場合の表示・初期解決値（`CatalogPricingService::resolveWholesaleAmount`）。
- **BP独自品目**: 「仕切り」として自社原価・仕切りを入れる。親からの卸価格とは別物。

### 推奨価格（`recommended_price`）

- **意味**: 販売時の目安・カタログ推奨。社内ガイドや画面表示用。
- **使わないこと**: 契約初期値・請求・キックバック・フォールバックのいずれにも**参加しない**。
- **運用イメージ**: 「カタログ上はこれくらいで売るとよい」という参考値。実際の売価はユーザー標準やカスタマー価格・契約単価で決める。

### ユーザー標準（`user_price`）

- **意味**: カスタマー（旧称エンドユーザー）向けの標準売価。
- **使うとき**:
  - `customer_prices` 未設定時の解決値（`resolveCustomerAmount`）
  - オーダー作成時の **`contract_items.unit_price` 初期値**
- **請求との関係**: 最終的に契約の `unit_price` がカスタマー請求に使われる。ユーザー標準そのものが請求に直結するわけではなく、「未設定時の出発点」。

### よくある混同

| 混同しやすい組 | 整理 |
|----------------|------|
| 推奨価格 vs ユーザー標準 | 推奨＝参考のみ。ユーザー標準＝システムの既定売価 |
| ユーザー標準 vs 契約の請求額 | 契約作成後は契約明細の `unit_price` が正。変更は契約／価格承認の世界 |
| 標準仕切り vs 契約の仕切り | 標準仕切りはマスタ既定。契約では卸解決後の値が `partition_price` に載る |

## 2. 個別設定価格（マスタ上書き）

### 卸価格（`bp_wholesale_prices`）

- 親BPが **直接の子BP** にだけ設定（ABAC: 隣接階層）。
- 未設定 → 品目の **標準仕切り** を表示・使用。
- 契約作成時、管理BPの親からの卸として契約明細の仕切り初期値に使われる。

### カスタマー価格（`customer_prices`）

- 管理BPが自配下カスタマーに設定。
- 未設定 → 品目の **ユーザー標準** を表示・使用。
- 契約作成時、EU単価（`unit_price`）の初期値に使われる。

---

## 3. 契約明細上の価格

| カラム | 意味 |
|--------|------|
| `unit_price` | カスタマーへの請求単価（税別） |
| `partition_price` | 当該管理BPが親から見た仕切り（税別）。特価申請時は希望仕切り |
| `standard_partition_price` | 申請時点の通常仕切り（卸値解決結果）。差額表示用 |
| `price_locked` | 価格承認後ロック |
| `contract_item_price_layers` | 承認時に親子区間の仕切りをスナップショット |

契約ヘッダ:

| カラム | 意味 |
|--------|------|
| `special_price_requested` | 特価申請あり |
| `special_price_reason` | 特価申請理由 |

- オーダー作成画面で「特価申請する」にチェックすると希望仕切り・理由を入力でき、作成と同時に親BPへ価格承認（特価）を申請する。
- 承認側の明細・価格タブに「特価申請あり」バッジ・理由・通常仕切りとの差額を表示する。
- オーダー作成中〜承認前は変更可（権限に従う）。
- 承認後はロック。変更は価格変更申請。
- **カスタマー請求金額 = `unit_price`（数量等は現状1）**。仕切りは請求に使わない。

## 4. 請求・キックバックでの参照

```text
カスタマー請求（ルートBP発行）
  └─ 契約明細 unit_price  （仕切り・推奨・ユーザー標準は直接参照しない）

キックバック（BP間）
  └─ 上値: より顧客側の単価（葉側は unit_price）
  └─ 下値: 価格レイヤの仕切り（親子区間）
  └─ 差額 = 上値 − 下値（負ならエラー）
```

詳細は [phase10-setup.md](phase10-setup.md) / [phase10-plan.md](phase10-plan.md)。

## 5. 解決の優先順位（フォールバック）

### カスタマー向け売価（契約初期の EU単価）

1. `customer_prices`（当該 BP・カスタマー・品目）  
2. なければ `items.user_price`（ユーザー標準）  
3. ※ `recommended_price` は使わない  

### BP 間仕切り（契約初期の仕切り）

1. `bp_wholesale_prices`（親→子・品目）  
2. なければ `items.partition_price`（標準仕切り）  

### 請求生成時

1. 契約明細に確定した `unit_price` / レイヤのみ使用  
2. 品目マスタの推奨・ユーザー標準・標準仕切りは再参照しない
