# Phase 5 実装メモ

## 合意済み方針

| 項目 | 内容 |
|------|------|
| A. 申込主体 | **BP**（自配下カスタマー／拠点）。管理者は代理作成・参照可 |
| B. 契約ステータス | `draft` → `pending_price_approval` → `approved` → `activated`／`cancelled` |
| C. 明細 | 品目・請求額・仕切り・`price_locked`。必須セット未充足は申込不可 |
| D. 仕切り初期値 | 親→自の卸価格（なければ品目標準）。承認前は変更可 |
| E. 価格承認 | 直近親BPへ申請。承認でロック。高額は ABAC P3 |
| F. 変更申請 | ロック後も価格変更申請可。再承認で再ロック |
| G. Documentテンプレート | 品目に紐づく共通ファイル。**Excel / XML / HTML のみ**・**品目あたり最大5**。契約時にコピーされ契約画面から確認・DL |
| H. カスタマー | 自契約の参照・ドキュメントDL・データの閲覧 |
| I. データ | 明細ごとに **名称:値** を複数。名称マスタ（管理者）＋マスタ外はBP直接入力可 |

## スコープ

| 含む | 含まない（後続） |
|------|------------------|
| contracts / contract_items / applications / 履歴 | 問い合わせ・お知らせ（Phase 6） |

| Documentテンプレート（最大5）・契約への紐付けDL | 任意Excel→PDF変換エンジン（テンプレPDF/HTML発行で代替） |
| 管理者 / BP / カスタマー画面 | 請求・決済 |

## 画面補足（更新）

- オーダー作成中（DB: `draft`）の契約は確認コード付きで削除可
- 新規は **カスタマー一覧 → 拠点選択 → 品目一覧 → オーダー作成** の順。状態は「オーダー作成中」。概要タブに未申請の警告を表示


- `contracts` / `contract_items` / `contract_status_histories`
- `applications`（price_approval / price_change）
- `data_field_names`（名称マスタ）
- `contract_item_data`（名称・値）
- `item_documents`（Documentテンプレート・品目あたり最大5）
- `contract_item_documents`（契約明細に発行・添付されたファイル）
