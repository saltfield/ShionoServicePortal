## 実装メモ

- ルート名は `*.tickets.*`（`received` / `issued` / `create` / `show` 等）。権限コードは既存 `inquiry.*` を流用。
- 管理者は受領のみ（代理起票なし）。カスタマー／BPは受領＋発行。
- 添付は `local` ディスク `ticket-attachments/`。プレビュー可は PNG/JPEG/GIF。
- 未読はスレッド単位（相手の user メッセージが既読時刻より新しいチケット数）。
