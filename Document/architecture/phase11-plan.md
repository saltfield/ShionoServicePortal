# Phase 11 計画 — デザイン刷新

## 目的

機能追加（Phase 2〜10）で積み上がった画面・ナビ・コンポーネントを、**見た目と情報設計の観点から刷新**する。  
ビジネスロジックや DB スキーマの大幅変更は行わず、UX・アクセシビリティ・一貫性を優先する。

※ 旧 Phase 10 から延期。

## スコープ案

| トラック | 内容 | 備考 |
|----------|------|------|
| **A. デザインシステム** | カラー・タイポ・余白・コンポーネント規約の文書化 | Bootstrap ベースのまま拡張 or テーマ層 |
| **B. レイアウト刷新** | ヘッダー / サイド / コンテンツ幅、モバイル対応の見直し | Phase 7 シェルを土台 |
| **C. 画面テンプレート** | 一覧・詳細・フォーム・ダッシュボードの見た目統一 | 三種ポータルでトーンを揃える |
| **D. フィードバック UI** | アラート・空状態・ローディング・確認ダイアログの統一 | |

## 含まない（後続）

- 外部決済 / 会計連携
- メール招待・マジックリンク
- Redis / WebSocket リアルタイム
- 帳票デザイナ・版管理・Word

## Step（案）

| Step | 内容 |
|------|------|
| 11-0 | デザイン方針合意（トーン、参照モック、Bootstrap 継続可否） |
| 11-A | デザイントークン・共通 CSS / コンポーネント |
| 11-B | レイアウト・ナビの刷新 |
| 11-C | 主要画面の適用（ログイン→ダッシュ→一覧→詳細） |
| 11-D | 回帰テスト・スクリーンショット更新 |
